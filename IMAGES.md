# Remplacer les illustrations par de vraies photos

Déposez vos photos dans `wp-content/themes/baobab-gourmand/assets/img/` **avant** de lancer `setup.sh`,
en gardant exactement les mêmes noms de fichiers (format JPG, paysage 4:3 sauf mention). Le script les importe
automatiquement dans la médiathèque. Sur un site déjà installé, remplacez-les via Médias > Modifier l'image.
